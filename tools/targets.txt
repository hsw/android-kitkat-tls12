# Release build inputs of tools/kktls-release-build.sh (one keyword per line, # starts a comment).
#   target  TAG LUNCH ABI   one release build: AOSP tag, lunch combo, Android ABI name (output dir out/kktls/TAG/ABI)
#   project PATH            AOSP manifest path synced (depth 1) for every tag; found by the Task 1 discovery builds
#   rev     TAG PATH SHA    the commit PATH must have after `sync` of TAG (every project of every tag needs one)
#   module  NAME            make goal built for every target (layer A modules, then the layer D modules)
#   file    PATH            release file collected from PRODUCT_OUT/system/PATH; a missing one fails the build
# Variant: -user (no gnu_debuglink in stripped .so files) with WITH_DEXPREOPT=false on the make command line, so every
# jar keeps its classes.dex (the release replaces jars on devices whose other .odex files then get re-dexopted).
